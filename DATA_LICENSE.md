# Data license / 데이터 라이선스

This software collects data from PRISM (정책연구관리시스템, prism.go.kr) via the
Korean public data portal open API. The MIT license in [LICENSE](LICENSE) covers the SOFTWARE ONLY.

Collected data is governed separately:
  - API metadata: "이용허락범위 제한 없음" (data.go.kr dataset 15080254)
  - Report full texts: KOGL (공공누리) Type 1-4, assigned PER TASK. Types 3 and 4
    prohibit modification and/or commercial use. Check each task's KOGL type
    (shown by `show <research_id>`) before redistributing or quoting.
  - Unlabeled items must be treated as non-redistributable.

No data is bundled with this repository. Each user collects their own with their
own API key.
