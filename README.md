# prism-db

**정책연구관리시스템(PRISM)의 정부·지자체 정책연구용역 7만여 건을 로컬 SQLite로 내려 검색하는 CLI.**
공공데이터포털 오픈API로 수집하고, 보고서 원문(PDF·HWP·HWPX)까지 받아 **본문 전문검색**을 붙인다.

"정부가 이 주제를 이미 연구했나 / 누가 얼마에 했나 / 그 보고서 어디에 뭐라 썼나"를 초 단위로 답한다.

- 데이터는 **함께 배포하지 않는다** — 각자 무료 API 키를 받아 10분이면 전수 수집한다([SETUP.md](SETUP.md))
- 구현은 `prism_db.py` 하나, **표준 라이브러리만으로 동작**한다(원문 추출기만 선택 설치)
- 실측 규모: 과제 **74,129건**(1998~2026), 상세·원문은 관심 분야만 골라 수집

```bash
git clone https://github.com/parkjui92/prism-db.git ~/prism-db
mkdir -p ~/.prism && printf '%s' '<공공데이터포털 Decoding 키>' > ~/.prism/key && chmod 600 ~/.prism/key
python3 ~/prism-db/prism_db.py sweep          # 약 75회 호출·10분 → 74,000여 건 적재
python3 ~/prism-db/prism_db.py search "인공지능 윤리" --limit 10
```

## 명령

| 명령 | 용도 |
|------|------|
| `search <검색어> [--sci] [--org 기관] [--year YYYY] [--strict]` | **메타 검색**(과제명·초록·목차·주제어) — 전수 대상 |
| `search <검색어> --fulltext` | **본문 검색** — 내려받은 보고서 본문에서 **해당 대목을 스니펫**으로 |
| `show <research_id>` | 한 과제 전체(계약방식·계약금액·초록·목차·원문링크·공공누리) |
| `stats` · `quota` | DB 현황 · 오늘 API 호출 수 |
| `sweep` | 목록 전수 수집(약 75회 호출) |
| `enrich [--sci] [--limit N]` | 상세 보강 — 과제당 1회 호출 |
| `files [--sci] [--limit N] [--budget-gb N]` | 원문 다운로드(API 쿼터와 무관) |
| `extract [--limit N]` | 원문 → 본문 텍스트 추출 → 전문검색 편입 |
| `clean` · `reclassify` | 적재분 정리 · 분야 분류 재판정 |

`search`·`show`·`stats`는 **로컬 DB만 읽어 쿼터를 쓰지 않는다.** 조사 중 마음껏 호출하면 된다.

수집한 것은 `~/.prism/`에 모인다(`prism.db` · `files/` · `key`). 저장소 안에는 아무것도 쌓이지 않는다.

## 얻는 필드

과제명 · 발주기관 · 담당부서 · 연구책임자 · 수행기관 · 연구기간 · BRM 연구분야 ·
**계약방식** · **계약금액** · 초록 · 목차 · 주제어 · **원문 다운로드 URL** · **공공누리 유형** · 원문공개여부

계약방식·계약금액이 붙어 있어 "어느 부처가 어떤 주제에 얼마를, 수의계약인지 입찰인지, 누구에게 주는가"를
통계로 낼 수 있다. 발주 단가의 현실적 기준선을 잡을 때 쓴다.

## 자동 갱신

`daily_update.sh`가 신규 발주 스윕 → 상세 보강 → 원문·본문 수집 → **발주 레이더 리포트**를 한 번에 한다.
macOS는 [`examples/`](examples/)의 launchd plist로 등록한다(절전으로 놓친 실행을 깨어난 뒤 따라잡는다).
Linux는 cron으로 같은 스크립트를 돌린다. 설치는 [SETUP.md](SETUP.md) 4절.

무인 실행 안전장치: **쿼터 950회 자동 정지 + 다음 날 이어받기**, **원문 저장 상한**(기본 20GB),
로그 5MB 자동 절단, 레이더 30일 자동 정리.

## ★반드시 알아야 할 함정 (전부 실측)

이 도구를 만들며 실제로 걸린 것들이다. 직접 API를 다루더라도 아래는 알고 가는 게 좋다.

1. **날짜 필터는 '연구기간 포함관계'다.** `start_date`~`end_date` 안에 연구 시작·종료가 **모두** 들어가야 반환된다. 연도별로 쪼개 훑으면 **해를 넘기는 과제가 통째로 누락**된다 — 실측으로 연도 분할 54,730건 vs 단일 범위 74,129건, **26%가 조용히 사라졌다.** 각 연도가 `totalCount`와 정확히 일치해서 겉보기엔 완벽해 보였다. `sweep`은 항상 단일 범위로 페이징한다.
2. **상세 조회 실패 ≠ 과제 부재.** 부분공개·비공개 과제는 상세 API가 "조회할 수 없는 과제입니다"를 반환한다. 도구가 `pnnMetaData_v2`로 폴백해 메타는 확보하고 `meta_only`로 기록한다. **"자료 없음"이 아니라 "원문 비공개"다.**
3. **계약방식은 코드로 온다.** 명칭이 아니라 `D01300xx` 코드다(웹 화면만 명칭 표시). 표본 과제의 웹 화면과 1:1 대조해 복원한 코드표를 내장했다 — D0130001 일반경쟁입찰 / D0130002 제한경쟁입찰 / D0130004 수의계약 / D0130005 기타 / D0130006 경쟁입찰 후 수의계약. 표에 없는 코드가 나오면 원값을 남기고 경고한다.
4. **공공누리 유형은 과제마다 다르다.** API 라이선스가 "제한 없음"이어도 **원문에는 제1~제4유형이 각각** 붙는다. 제3·4유형은 변경금지·상업금지다. 인용·재배포 전 `show`로 확인하고, 미표기는 재배포 금지로 취급한다.
5. **PRISM ≠ NTIS.** PRISM은 행정수요 기반 **정책연구용역**, NTIS는 **국가 R&D 과제**다. 모집단이 달라 합산·비교하면 즉시 오류다.
6. **최근 연도 과소는 등록 시차다.** 발주 감소가 아니다. 최근 1~2년으로 추세를 주장하지 않는다.
7. **원문 서버의 TLS 체인이 불완전하다.** `api.prism.go.kr`이 중간 인증서 대신 리프를 두 번 보내 파이썬에서 `CERTIFICATE_VERIFY_FAILED`가 난다(시스템 openssl은 캐시된 중간 인증서로 통과해 증상이 가려진다). 도구가 AIA 발급자 인증서를 받아 신뢰번들에 보강한다 — **검증을 끄지 않고** 서버가 빠뜨린 조각을 채운다.
8. **한 과제에 원문이 여러 개일 수 있다.** 장별 분할 PDF(표지·목차·제4장…)로 올라온다. "보고서 1건 = 파일 1건"이 아니다.
9. **"원문 공개"인데 파일이 비어 있을 수 있다.** 발주기관이 빈 껍데기를 올린 사례를 실측했다(zip 278바이트, 내부 선언 크기 0). 도구는 `empty-source`로 남겨 **추출 실패와 구분**한다. 다운로드 단계에서도 0바이트·잘린 응답은 거부하고 재수집 대상으로 되돌린다. 스캔 이미지 PDF도 본문이 안 나오므로 **"원문 공개 = 본문 확보"가 아니다.**

## ★한국어 검색·분류의 함정

이 도구가 가장 공들인 부분이고, 한국어 텍스트를 다루는 다른 작업에도 그대로 적용된다.

**검색 — FTS만 쓰면 대량으로 놓친다.** SQLite FTS5(unicode61)는 한국어를 어절 단위로 쪼개서
짧은 말이 합성어에 박히면 통째로 못 잡는다. 실측 누락률이 **`규제` 71%(260/901) · `특허` 66% · `양자` 55%**였다
(긴 합성어는 양호: `인공지능` 2%). trigram 토크나이저는 **3글자 미만 질의를 아예 못 해서**
규제·양자·특허 같은 2음절 정책용어에 쓸 수 없다.

→ **FTS(순위)와 부분일치 전수 스캔(빠짐없음)을 합친다.** 스캔은 메타 0.02초·본문 0.21초로 사실상 공짜다.
FTS가 찾은 것이 먼저 오고, 부분일치로만 걸린 건 **`[보정]`으로 표시**된다.
`[보정]`에는 어절 경계를 넘은 걸침이 섞인다(`양자`에 兩者間·휴양자원). 그래도 기본 포함하는 이유는
**두 오류의 대가가 비대칭**이기 때문이다 — 놓치면 "선행연구 없음"이라는 틀린 결론이 보고서에 실리고,
오탐은 제목 한 줄 보고 넘기면 그만이다. 정확일치만 원하면 `--strict`.

**분류 — 부분일치는 오탐을 대량 만든다.** `--sci`(과학기술) 분류에서 **646건(11.5%)이 오분류**였다.
`AI`가 AIS·CAIV·Aid for Trade에 걸리고, 무엇보다 **한국 정부 문서에서 `AI`는 조류인플루엔자**인 경우가 흔하다
("AI 방역체계", "고병원성 AI"). `양자`는 兩者間·휴양자원에, `실증`은 실증연구(경험적 연구)에 걸린다.
→ 라틴 약어에 **단어경계**를, 다의어에 **뒤따르는 말**을 요구하고,
조류인플루엔자 문맥에서는 **`AI` 매치만 무효화한 뒤 나머지 키워드로 다시 판정**한다.

다른 분야(복지·환경·교육 등)로 바꾸려면 `SCI_KEYWORDS`·`SCI_REGEX_EXTRA`를 고치고 `reclassify`를 돌린다.

## 요구사항

- Python 3.8+ (표준 라이브러리만으로 수집·검색 동작)
- 원문 본문 추출은 선택 설치 시 품질이 좋아진다: `pip install pymupdf olefile`
  (PDF=PyMuPDF→pypdf 폴백, HWPX=zip+XML 내장, **HWP 5.0=OLE+zlib 직접 파싱**, ZIP=내부 재귀)
- 공공데이터포털 인증키(무료·자동승인, 개발계정 일 1,000회)
